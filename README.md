# Radex International

Radex International helps drivers find OEM, aftermarket and performance car parts worldwide. Browse customer builds and upgrades, explore the gallery, or send a part request through WhatsApp.

Built with React, React Router and Vite.

## Run locally

```sh
npm install
npm run dev
```

Build with `npm run build`; Vite writes the deployable site to `dist/`.

The home hero video autoplays when the browser allows it. On iPhones in Low Power Mode, iOS may block autoplay; the hero then displays a still image instead.
